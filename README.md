One line, at most 200 characters, about the dumbest thing my own agent did today: it downloaded a 17 MB toolkit and read 860 lines of rules twice, just to write this one sentence.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (set `OUTPUT_DIR` to write it elsewhere).
